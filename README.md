# 8Galer

Overlay Android ringan untuk garis bantu meja biliar.

## Pemakaian

1. Instal APK dari artifact GitHub Actions.
2. Buka 8Galer, izinkan **Display over other apps**, lalu aktifkan overlay.
3. Tahan bola pintasan **8** untuk masuk mode kalibrasi.
4. Geser empat cincin kuning transparan ke empat lubang sudut. Dua lubang tengah dihitung otomatis.
5. Saat mode kalibrasi, tap tombol **●** untuk mengganti warna garis; tahan untuk mengunci.
6. Geser cincin biru ke bola target. Keenam garis langsung mengikuti.
7. Tap bola pintasan untuk menampilkan atau menyembunyikan panduan; geser untuk memindahkannya.

Build hanya memakai Android API native; tanpa dependency aplikasi pihak ketiga.
