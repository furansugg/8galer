# 8Galer

Overlay Android ringan untuk garis bantu meja biliar.

## Pemakaian

1. Instal APK dari artifact GitHub Actions.
2. Buka 8Galer, izinkan **Display over other apps**, lalu aktifkan overlay.
3. Tahan bola pintasan **8** untuk masuk mode kalibrasi.
4. Geser enam cincin kuning transparan tepat ke enam lubang, lalu tahan **✓** untuk mengunci.
5. Geser cincin biru ke bola target. Keenam garis langsung mengikuti.
6. Tap bola pintasan untuk menampilkan atau menyembunyikan panduan; geser untuk memindahkannya.

Build hanya memakai Android API native; tanpa dependency aplikasi pihak ketiga.
