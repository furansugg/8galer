# 8Galer

Overlay Android ringan untuk garis bantu meja biliar.

## Pemakaian

1. Instal APK dari artifact GitHub Actions.
2. Buka 8Galer, izinkan **Display over other apps**, lalu aktifkan overlay.
3. Geser empat titik kuning ke empat sudut meja.
4. Geser lingkaran biru ke bola target.
5. Tap bola pintasan **8** untuk menampilkan atau menyembunyikan panduan. Bola pintasan sendiri dapat digeser.

Build hanya memakai Android API native; tanpa dependency aplikasi pihak ketiga.
